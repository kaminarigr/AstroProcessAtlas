# Contributing to AstroProcessAtlas

AstroProcessAtlas is a free, open source PixInsight tool created and maintained by
**YoruHikari — [YoruHikari Astrophotography](https://www.yoruhikari.gr/)**.

You can help without writing code:

- Test reports and replay on your own workflows and describe what worked.
- [Report a problem](https://github.com/kaminarigr/AstroProcessAtlas/issues/new?template=bug_report.yml).
- [Suggest an improvement](https://github.com/kaminarigr/AstroProcessAtlas/issues/new?template=feature_request.yml).
- Share the project link and credit its author when presenting your workflow.
- Improve the documentation, translations or examples; use only material you may publish.

Participation is optional. There is currently no donation or sponsorship link.
No payment is required to use the tool.

## Reporting a problem

Read [SUPPORT.md](SUPPORT.md). Include the AstroProcessAtlas and PixInsight
versions, browser if relevant, reproduction steps, expected/actual behavior and
the exact error. For replay failures, include a reviewed excerpt of the final
report or execution trace. Do not attach a full private HTML report by default.

GitHub issues are public. Remove private image names, personal paths and other
information you do not want published. Opening a feedback link does not send
your images, report or logs automatically.

## Code changes

Describe the problem and proposed behavior in an issue or pull request. Keep
changes focused and follow the existing PJSR-compatible JavaScript style.
Run the checks listed in the README. Test PixInsight-specific behavior in
PixInsight when possible and distinguish native tests from simulated tests.

For fixes, link the real issue with `Refs #…`, identify the target release and add
an issue link to the changelog. Use the PR template and the
[issue management guide](docs/ISSUE_MANAGEMENT.md). Keep committed/merged fixes
separate from released fixes; post the version/release link before closing a
resolved report after publication.

Retain the existing copyright and license notices. AstroProcessAtlas is under
the MIT License; replay exports embedding DarkStructureEnhance have separate
GPL notices documented in the README.

## Ελληνικά

Μπορείς να βοηθήσεις με δοκιμές, αναφορές προβλημάτων, προτάσεις, βελτίωση οδηγιών
και κοινοποίηση του project με αναφορά στον YoruHikari. Δεν απαιτούνται χρήματα
ή γνώσεις προγραμματισμού. Δεν υπάρχει προς το παρόν σύνδεσμος δωρεάς.

Τα GitHub issues είναι δημόσια. Πριν κοινοποιήσεις log ή screenshot, αφαίρεσε
προσωπικές διαδρομές, ονόματα εικόνων ή άλλο ιδιωτικό περιεχόμενο. Οι σύνδεσμοι
feedback δεν αποστέλλουν αυτόματα δεδομένα.
